## 🎯 Objectifs de gestion (Testing GitHub)
Pour chaque nouveau langage ajouté, le workflow suivant doit être respecté :

1.  **Issue Creation** : Créer une issue dans le dépôt cible.
2.  **Project Linking** : Rattacher l'issue au tableau de bord central "Master Project".
3.  **Branching** : Créer une branche `feature/hello-world` via l'issue.
4.  **Pull Request** : Soumettre une PR avec le mot-clé `Closes #ID` pour automatiser la fermeture.
5.  **Labeling** : Appliquer les labels appropriés (`langage`, `difficulty`, `environment`).
